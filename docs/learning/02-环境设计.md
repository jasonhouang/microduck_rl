# 环境设计

## 概述

Microduck RL 中的每个训练环境都由三个核心部分组成：

1. **观察空间（Observation Space）**：智能体能看到的信息
2. **动作空间（Action Space）**：智能体能执行的控制
3. **奖励函数（Reward Function）**：指导学习的目标信号

这些环境基于 mjlab 框架的 ManagerBasedRlEnv 设计，通过配置化的方式定义各个组件。

## 观察空间（61 维）

所有策略共享统一的 61 维观察空间，这是 sim2real 的关键设计。

### 观察组成

```
观察向量（61 维）
├── 本体感知（48 维）
│   ├── 角速度（3 维）：躯干角速度 [ωx, ωy, ωz]
│   ├── 投影重力（3 维）：重力在躯干坐标系的投影 [gx, gy, gz]
│   ├── 关节位置（14 维）：相对于 HOME 位置的偏移
│   ├── 关节速度（14 维）：关节角速度
│   ├── 历史动作（14 维）：上一步的动作输出
│   └── 相位变量（可选，通常 0 维）
│
└── 控制指令（13 维）
    ├── 速度指令（3 维）：[vx, vy, ωz]
    ├── 头部姿态（4 维）：[neck_pitch, head_pitch, head_yaw, head_roll]
    └── 身体姿态（6 维）：[x, y, z, roll, pitch, yaw]
```

### 关节布局

14 个可控关节的索引顺序：

```python
# 左腿（5 个）
0: left_hip_yaw      # 髋关节偏航
1: left_hip_roll     # 髋关节横滚
2: left_hip_pitch    # 髋关节俯仰
3: left_knee         # 膝关节
4: left_ankle        # 踝关节

# 头部（4 个）
5: neck_pitch        # 颈部俯仰
6: head_pitch        # 头部俯仰
7: head_yaw          # 头部偏航
8: head_roll         # 头部横滚

# 右腿（5 个）
9: right_hip_yaw     # 髋关节偏航
10: right_hip_roll   # 髋关节横滚
11: right_hip_pitch  # 髋关节俯仰
12: right_knee       # 膝关节
13: right_ankle      # 踝关节
```

注意：`mouth` 关节（索引 9）不参与策略控制，但在物理模型中存在。

### 观察归一化

所有观察值在输入网络前都会归一化：

```python
# 归一化器在导出时烘焙到 ONNX 模型中
# 训练时自动应用，推理时无需手动处理

# 典型归一化范围
joint_pos: ±π (归一化到 ±1)
joint_vel: ±10 rad/s (归一化到 ±1)
angular_vel: ±5 rad/s (归一化到 ±1)
gravity: 已经是单位向量，无需归一化
```

### 观察噪声

为了提高鲁棒性，训练时会添加噪声：

```python
# microduck_velocity_env_cfg.py
ENABLE_OBSERVATION_NOISE = True

OBSERVATION_NOISE_SCALES = {
    "joint_pos": 0.01,      # 1% 噪声
    "joint_vel": 0.05,      # 5% 噪声
    "angular_vel": 0.05,    # 5% 噪声
    "gravity": 0.02,        # 2% 噪声
}
```

噪声在每次重置时随机采样，每个环境的噪声独立。

## 动作空间（14 维）

动作空间直接对应 14 个舵机的目标位置。

### 动作定义

```python
# 动作是相对于 HOME 位置的偏移
action = [Δq0, Δq1, ..., Δq13]

# 实际目标位置
target_position = HOME_POSITION + action_scale * action

# action_scale 通常在 0.25-0.5 之间
# 限制动作幅度，防止过大运动
```

### HOME 位置

HOME 位置是机器人的标准站立姿态：

```python
# src/mjlab_microduck/robot/microduck_constants.py
HOME_POSITION = [
    # 左腿
    0.0,      # hip_yaw
    0.0,      # hip_roll
    -0.4,     # hip_pitch (略微弯曲)
    0.8,      # knee (弯曲)
    -0.4,     # ankle
    
    # 头部
    0.0,      # neck_pitch
    0.0,      # head_pitch
    0.0,      # head_yaw
    0.0,      # head_roll
    
    # 右腿
    0.0,      # hip_yaw
    0.0,      # hip_roll
    -0.4,     # hip_pitch
    0.8,      # knee
    -0.4,     # ankle
]
```

### 动作平滑

训练时不使用动作滤波器（低通滤波），但部署时可能会添加：

```python
# 训练时：直接输出动作
action_t = policy(observation_t)

# 部署时（可选）：添加低通滤波
action_t = alpha * action_t + (1 - alpha) * action_t-1
# alpha 通常 0.5-0.8
```

**重要**：训练和部署的滤波设置必须一致，否则会导致性能下降。

## 控制指令

控制指令告诉机器人"想做什么"，是观察的一部分。

### 速度指令（3 维）

```python
# 在机器人躯干坐标系中
vx:  前后速度（前正后负），范围 ±0.5 m/s
vy:  左右速度（右正左负），范围 ±0.3 m/s
ωz:  旋转速度（逆时针正），范围 ±1.0 rad/s

# 指令采样
# 训练时随机采样，让策略学会各种速度
# 部署时由用户或高层策略提供
```

### 头部姿态指令（4 维）

```python
# 相对于 HOME 位置的偏移
neck_pitch:  颈部俯仰，范围 ±0.3 rad
head_pitch:  头部俯仰，范围 ±0.3 rad
head_yaw:    头部偏航，范围 ±0.5 rad
head_roll:   头部横滚，范围 ±0.3 rad

# 用于：
# - 看特定方向
# - 保持水平（补偿身体倾斜）
# - 表达"注意力"
```

### 身体姿态指令（6 维）

```python
# 相对于 HOME 位置的偏移
x:     前后偏移，范围 ±0.05 m
y:     左右偏移，范围 ±0.05 m
z:     上下偏移，范围 ±0.05 m
roll:  横滚偏移，范围 ±0.2 rad
pitch: 俯仰偏移，范围 ±0.2 rad
yaw:   偏航偏移，范围 ±0.2 rad

# 用于：
# - 调整重心位置
# - 倾斜身体（例如转弯时）
# - 蹲下或站高
```

### 指令采样策略

```python
# 训练时随机采样指令
def resample_commands(env_ids):
    # 速度指令
    vx = uniform(-0.5, 0.5)
    vy = uniform(-0.3, 0.3)
    ωz = uniform(-1.0, 1.0)
    
    # 15% 的环境专门练习原地旋转
    if random() < 0.15:
        vx = 0.0
        vy = 0.0
        ωz = uniform(0.4, 1.0) * sign(random())
    
    # 头部和身体指令
    # 通常采样小范围，让策略学会稳定
    head_pose = uniform(-0.1, 0.1, size=4)
    body_pose = uniform(-0.02, 0.02, size=6)
```

## 任务配置系统

每个任务由一个配置文件定义，继承自基础配置。

### 配置结构

```python
# src/mjlab_microduck/tasks/microduck_velocity_env_cfg.py

@dataclass
class MicroduckVelocityEnvCfg:
    # 场景配置
    scene: SceneCfg
    
    # 观察配置
    observations: ObservationCfg
    
    # 奖励配置
    rewards: RewardCfg
    
    # 事件配置（域随机化、重置等）
    events: EventCfg
    
    # 指令配置
    commands: CommandCfg
    
    # 终止条件
    terminations: TerminationCfg
    
    # 课程学习
    curriculum: CurriculumCfg
```

### 配置继承

```python
# 基础配置（行走）
class MicroduckVelocityEnvCfg:
    # 基础设置...

# 继承并修改（摔倒恢复）
class MicroduckVelStandEnvCfg(MicroduckVelocityEnvCfg):
    # 覆盖特定配置
    rewards: RewardCfg = replace(
        MicroduckVelocityEnvCfg.rewards,
        fall_penalty=10.0,  # 增加摔倒惩罚
        recovery_bonus=5.0, # 添加恢复奖励
    )
    
    events: EventCfg = replace(
        MicroduckVelocityEnvCfg.events,
        spawn_fallen=True,  # 从摔倒状态开始
    )
```

### 配置参数示例

```python
# 域随机化开关
ENABLE_COM_RANDOMIZATION = True
ENABLE_MASS_RANDOMIZATION = True
ENABLE_FRICTION_RANDOMIZATION = True
ENABLE_IMU_NOISE = True

# 随机化范围
COM_OFFSET_RANGE = (0.0, 0.02)  # 0-2cm
MASS_RANGE = (0.8, 1.2)         # ±20%
FRICTION_RANGE = (0.5, 2.0)     # 50%-200%
IMU_NOISE_STD = 0.01            # 1% 噪声

# 奖励权重
REWARD_WEIGHTS = {
    "tracking": 1.0,            # 跟踪指令
    "upright": 2.0,             # 保持直立
    "energy": -0.001,           # 能量消耗（负权重）
    "smoothness": -0.01,        # 动作平滑（负权重）
    "foot_slip": -0.1,          # 脚打滑（负权重）
}

# 终止条件
TERMINATION_CONDITIONS = {
    "fallen": FallCondition(max_tilt=0.8),  # 倾斜超过 45°
    "timeout": TimeoutCondition(max_time=20.0),  # 超时 20 秒
}
```

## 关节命名约定

### 主动关节 vs 被动关节

```python
# 主动关节（有执行器）
# 命名：直接描述关节功能
"left_hip_yaw"
"right_knee"
"head_pitch"

# 被动关节（无执行器）
# 命名：以 "passive_" 开头
"passive_left_wheel"      # 轮子（轮式变体）
"passive_mouth"           # 嘴部（不参与控制）
"passive_left_backlash"   # 齿轮间隙（backlash 变体）
```

### 关节索引辅助函数

```python
# 获取主动关节索引（排除 passive_ 关节）
def _servo_joint_ids(env, asset):
    """返回主动关节在物理模型中的索引"""
    all_joints = asset.joint_names
    servo_ids = [i for i, name in enumerate(all_joints) 
                 if not name.startswith("passive_")]
    return servo_ids

# 使用示例
servo_ids = _servo_joint_ids(env, robot)
joint_pos = robot.data.joint_pos[:, servo_ids]  # 只取主动关节
```

## 环境创建流程

```python
# 1. 加载配置
cfg = make_microduck_velocity_env_cfg()

# 2. 创建场景
scene = Scene(cfg.scene)

# 3. 创建环境
env = ManagerBasedRlEnv(
    scene=scene,
    observations=cfg.observations,
    rewards=cfg.rewards,
    events=cfg.events,
    commands=cfg.commands,
    terminations=cfg.terminations,
)

# 4. 初始化
env.reset()

# 5. 运行循环
for step in range(max_steps):
    obs = env.get_observations()
    action = policy(obs)
    obs, reward, done, info = env.step(action)
```

## 总结

环境设计的核心原则：

1. **统一接口**：所有任务共享 61 维观察和 14 维动作，支持热切换
2. **配置化**：通过 Python dataclass 定义，易于修改和继承
3. **物理真实**：关节布局、HOME 位置、动作范围都基于真实机器人
4. **鲁棒性**：观察噪声、指令随机化、地形变化提高泛化能力
5. **模块化**：观察、奖励、事件等组件独立配置，灵活组合
