# 执行器模型

## 概述

Microduck RL 使用 **BAM（Better Actuator Model）** 来模拟真实的 Dynamixel XL330 舵机。与传统的理想 PD 控制器不同，BAM 模拟了舵机的电压控制特性、摩擦、反电动势等物理效应，大幅缩小 sim2real 差距。

## 为什么需要真实执行器模型？

### 理想 PD 控制器的问题

```python
# 传统仿真使用的理想模型
τ = Kp * (q_target - q) + Kd * (q̇_target - q̇)

# 问题：
# 1. 假设扭矩可以瞬间达到目标值
# 2. 忽略电机的电气动力学
# 3. 忽略摩擦和反电动势
# 4. 在仿真中表现完美，部署到真实机器人失败
```

### BAM 模型的优势

```python
# BAM 模拟真实的电压控制
V = Kt * τ_target + Ke * ω + R * I
τ_actual = f(V, ω, friction, temperature)

# 考虑：
# 1. 电压-扭矩关系
# 2. 反电动势（back-EMF）
# 3. 摩擦（库仑摩擦、粘滞摩擦、Stribeck 效应）
# 4. 负载相关摩擦
```

## BAM 执行器架构

```
┌─────────────────────────────────────────────────────────────┐
│                    BAM 执行器模型                            │
│                                                             │
│  目标扭矩 τ_target                                          │
│       ↓                                                     │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  电压计算                                             │  │
│  │  V = Kt * τ_target + Ke * ω + R * I                  │  │
│  │  ├─ Kt: 扭矩常数                                      │  │
│  │  ├─ Ke: 反电动势常数                                  │  │
│  │  └─ R: 电阻                                           │  │
│  └──────────────────────────────────────────────────────┘  │
│       ↓                                                     │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  摩擦计算                                             │  │
│  │  τ_friction = τ_coulomb + τ_viscous + τ_striebek     │  │
│  │  ├─ τ_coulomb: 库仑摩擦（常数）                       │  │
│  │  ├─ τ_viscous: 粘滞摩擦（∝ 速度）                     │  │
│  │  └─ τ_striebek: Stribeck 效应（低速非线性）           │  │
│  └──────────────────────────────────────────────────────┘  │
│       ↓                                                     │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  实际扭矩                                             │  │
│  │  τ_actual = τ_target - τ_friction                    │  │
│  └──────────────────────────────────────────────────────┘  │
│       ↓                                                     │
│  关节加速度 q̈ = (τ_actual - τ_load) / I                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 摩擦模型

### 库仑摩擦（Coulomb Friction）

```python
# 常数摩擦，与速度方向相反
τ_coulomb = -τ_c * sign(ω)

# τ_c: 库仑摩擦系数
# 典型值: 0.05-0.15 Nm
```

### 粘滞摩擦（Viscous Friction）

```python
# 与速度成正比的摩擦
τ_viscous = -b * ω

# b: 粘滞摩擦系数
# 典型值: 0.001-0.01 Nm·s/rad
```

### Stribeck 效应

```python
# 低速时的非线性摩擦
τ_striebek = -(τ_s - τ_c) * exp(-(ω/ω_s)^α) * sign(ω)

# τ_s: Stribeck 摩擦（静止摩擦）
# ω_s: Stribeck 速度
# α: 指数（通常 1-2）
```

### 负载相关摩擦

```python
# 摩擦随负载增加
τ_friction_load = τ_friction * (1 + k_load * |τ_load|)

# k_load: 负载摩擦系数
# 这是 BAM 的关键特性，传统模型忽略
```

## 反电动势（Back-EMF）

```python
# 电机旋转时产生的反向电压
V_emf = Ke * ω

# Ke: 反电动势常数
# ω: 角速度

# 影响：
# 1. 高速时需要更高电压
# 2. 限制了最大速度
# 3. 提供自然的阻尼效应
```

## 电压控制律

```python
# 完整的电压-扭矩关系
V = Kt * τ_target + Ke * ω + R * I

# 求解电流
I = (V - Ke * ω) / R

# 求解扭矩
τ = Kt * I

# 其中：
# V: 供电电压（通常 12V）
# Kt: 扭矩常数
# Ke: 反电动势常数
# R: 绕组电阻
# ω: 角速度
# I: 电流
```

## 域随机化

### 摩擦随机化

```python
# src/mjlab_microduck/actuator/friction_dr_bam.py

class FrictionDRBamActuator(BamActuator):
    """BAM + 每环境摩擦随机化"""
    
    def initialize(self, mj_model, model, data, device):
        super().initialize(mj_model, model, data, device)
        # 每个环境独立的摩擦缩放因子
        self.friction_scale = torch.ones_like(self.kp_scale)
    
    def _compute_friction_budget(self, motor_torque, external_torque, stribeck_coeff):
        base = super()._compute_friction_budget(...)
        # 应用随机缩放
        return base * self.friction_scale
    
    def set_friction_scale(self, env_ids, friction_scale):
        """设置特定环境的摩擦缩放"""
        self.friction_scale[env_ids] = friction_scale
```

## Backlash 模拟

### 什么是 Backlash？

Backlash（齿轮间隙）是齿轮传动中的机械间隙。当电机反转时，需要先"吃掉"这个间隙才能带动负载。

```python
# 物理模型
# 电机侧: q_motor
# 负载侧: q_load
# 间隙: q_backlash

# q_load = q_motor + q_backlash
# |q_backlash| ≤ backlash_limit

# 当电机正转时：q_backlash = +backlash_limit
# 当电机反转时：q_backlash 从 +limit 过渡到 -limit
```

### Backlash 关节

```python
# 在 MJCF 模型中添加被动关节
<joint name="passive_left_hip_yaw_backlash" .../>

# 使用弹簧-阻尼器模拟间隙
<joint stiffness="100" damping="1"/>
```

### BacklashEncoderBamActuator

```python
class BacklashEncoderBamActuator(FrictionDRBamActuator):
    """
    模拟真实编码器的行为：
    编码器在负载侧，测量的是 q_motor + q_backlash
    """
    
    def initialize(self, mj_model, model, data, device):
        super().initialize(...)
        # 找到对应的 backlash 关节
        self._backlash_joint_ids = [...]
        self._backlash_mask = [...]
    
    def get_command(self, data):
        cmd = super().get_command(data)
        # 编码器读数 = 电机位置 + 间隙
        pos = cmd.pos + data.joint_pos[:, self._backlash_joint_ids] * self._backlash_mask
        return dataclasses.replace(cmd, pos=pos)
```

## 电压下降

```python
# 电池电压随负载下降
V_actual = V_battery - R_internal * I_total

# V_battery: 电池开路电压（12V）
# R_internal: 电池内阻
# I_total: 总电流（所有舵机）

# 影响：
# 1. 多个舵机同时运动时电压下降
# 2. 可用扭矩减少
# 3. 可能导致不稳定
```

### 电压下降随机化

```python
# 训练时模拟电压下降
ENABLE_VOLTAGE_SAG = True

def compute_voltage_sag(current):
    V_sag = V_battery - VOLTAGE_SAG_GAIN * current
    return V_sag
```

## 执行器模型对比

| 特性 | 理想 PD | BAM |
|------|---------|-----|
| 控制方式 | 直接扭矩 | 电压控制 |
| 摩擦 | 忽略 | 库仑+粘滞+Stribeck |
| 反电动势 | 忽略 | 考虑 |
| 负载影响 | 忽略 | 考虑 |
| 电压下降 | 忽略 | 考虑 |
| 齿轮间隙 | 忽略 | 可选模拟 |
| Sim2real 差距 | 大 | 小 |
| 训练速度 | 快 | 稍慢 |
| 物理真实性 | 低 | 高 |

## 调试技巧

### 检查执行器行为

```python
# 在训练日志中监控
def log_actuator_state(env):
    # 电压
    voltage = env.actuator_voltage
    print(f"Voltage: {voltage.mean():.2f}V")
    
    # 电流
    current = env.actuator_current
    print(f"Current: {current.mean():.2f}A")
    
    # 摩擦
    friction = env.actuator_friction
    print(f"Friction: {friction.mean():.3f}Nm")
    
    # 实际扭矩 vs 目标扭矩
    tau_actual = env.actuator_torque
    tau_target = env.actuator_torque_target
    print(f"Torque error: {(tau_actual - tau_target).abs().mean():.3f}Nm")
```

### 验证摩擦模型

```python
# 在零扭矩命令下观察减速
def test_friction():
```

## 总结

BAM 执行器模型是 sim2real 成功的关键：

1. **物理真实性**：模拟电压控制、摩擦、反电动势等真实效应
2. **域随机化**：摩擦参数随机化提高鲁棒性
3. **Backlash 模拟**：可选的齿轮间隙模拟
4. **电压下降**：模拟电池负载效应
5. **系统辨识**：参数通过真实机器人辨识获得

这些特性使得在仿真中训练的策略可以直接部署到真实机器人，无需额外调整。
