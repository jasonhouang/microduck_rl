# 域随机化

## 概述

域随机化（Domain Randomization, DR）是 sim2real 的核心技术之一。通过在训练时随机化仿真环境的物理参数，让策略学会在参数变化时仍能正常工作，从而提高部署到真实机器人时的鲁棒性。

## 为什么需要域随机化？

### Sim2real 差距来源

```
仿真环境                    真实环境
─────────                   ─────────
完美地形                     不平整地面
精确质量                     质量偏差 ±10%
无传感器噪声                 噪声、漂移
理想执行器                   摩擦变化、磨损
精确 CoM                    CoM 因电池/负载变化
无外部干扰                   推力、碰撞
```

### 域随机化的思想

```
训练时：让策略经历各种可能的物理参数
部署时：真实环境的参数只是其中一种情况

策略见过足够多的变化 → 对参数变化不敏感 → 部署成功
```

## 随机化参数一览

Microduck 对以下参数进行随机化：

| 参数 | 范围 | 说明 |
|------|------|------|
| 躯干 CoM 偏移 | ±3-8mm | 质心位置偏移 |
| 头部 CoM 偏移 | ±3mm | 头部质心偏移 |
| 质量/惯量 | ±5% | 身体各部分质量和惯量 |
| 关节摩擦 | ±10% | BAM 摩擦缩放因子 |
| 关节臂惯量 | ±10% | 电机转子反射惯量 |
| IMU 安装误差 | ±6° | IMU 安装角度偏差 |
| 编码器偏置 | ±0.86° | 关节位置测量偏移 |
| 速度推力 | ±0.3 m/s | 外部干扰 |
| 地面摩擦 | 变化 | 接触面摩擦系数 |

## 躯干 CoM 随机化

```python
# src/mjlab_microduck/tasks/mdp.py

def randomize_com(
    env: ManagerBasedRlEnv,
    env_ids: torch.Tensor,
    com_offset_range: tuple[float, float] = (0.0, 0.003),
):
    """随机偏移躯干质心位置"""
    robot = env.scene["robot"]
    
    # 采样随机偏移（3D）
    offset = torch.zeros(len(env_ids), 3, device=env.device)
    offset[:, 0] = uniform(-com_offset_range[1], com_offset_range[1])  # x
    offset[:, 1] = uniform(-com_offset_range[1], com_offset_range[1])  # y
    offset[:, 2] = uniform(-com_offset_range[1], com_offset_range[1])  # z
    
    # 应用到躯干 link
    trunk_body_id = robot.find_bodies("trunk_base")[0]
    robot.data.kinematic_com[env_ids, trunk_body_id] += offset
```

## 质量/惯量随机化

```python
def randomize_mass_inertia(
    env: ManagerBasedRlEnv,
    env_ids: torch.Tensor,
    mass_range: tuple[float, float] = (0.95, 1.05),
):
    """随机缩放质量和惯量"""
    robot = env.scene["robot"]
    
    # 采样缩放因子
    scale = uniform(mass_range[0], mass_range[1], size=(len(env_ids),), device=env.device)
    
    # 应用到所有 body
    for body_id in range(robot.num_bodies):
        # 质量缩放
        robot.data.body_mass[env_ids, body_id] *= scale
        
        # 惯量缩放（各向同性）
        robot.data.body_inertia[env_ids, body_id, 0] *= scale
        robot.data.body_inertia[env_ids, body_id, 1] *= scale
        robot.data.body_inertia[env_ids, body_id, 2] *= scale
```

## 关节摩擦随机化

```python
# src/mjlab_microduck/actuator/friction_dr_bam.py

def randomize_bam_friction(
    env: ManagerBasedRlEnv,
    env_ids: torch.Tensor,
    friction_range: tuple[float, float] = (0.9, 1.1),
):
    """随机化 BAM 执行器的摩擦缩放因子"""
    actuator = env.scene["robot"].actuators["legs"]
    
    # 采样缩放因子
    scale = uniform(friction_range[0], friction_range[1], size=(len(env_ids), 1), device=env.device)
    
    # 设置到执行器
    actuator.set_friction_scale(env_ids, scale)
```

### 非累积性

**关键原则**：域随机化必须是非累积的。每次重置时重新采样，而不是在上一次基础上累加。

```python
# 正确：重置到默认值，然后应用新采样
actuator.reset_friction_scale(env_ids)  # 先重置
actuator.set_friction_scale(env_ids, new_sample)  # 再设置

# 错误：在上一次基础上累加
actuator.friction_scale[env_ids] *= new_sample  # 会累积！
```

mjlab 1.3.0 的 `dr.*` 操作默认是非累积的（重新读取编译时默认值），但自定义 DR 函数必须手动实现这个行为。

## IMU 安装误差随机化

```python
def randomize_imu_orientation(
    env: ManagerBasedRlEnv,
    env_ids: torch.Tensor,
    max_angle_deg: float = 6.0,
):
    """随机化 IMU 安装角度"""
    robot = env.scene["robot"]
    
    # 采样随机旋转轴和角度
    axis = torch.randn(len(env_ids), 3, device=env.device)
    axis = axis / axis.norm(dim=1, keepdim=True)
    
    angle = uniform(0, max_angle_deg * DEG2RAD, size=(len(env_ids),), device=env.device)
    
    # 构建旋转四元数
    quat = quat_from_angle_axis(angle, axis)
    
    # 应用到 IMU 传感器
    imu_sensor = robot.sensors["imu"]
    imu_sensor.set_orientation_quat(env_ids, quat)
```

### 零中心 vs 偏置

IMU 随机化是**零中心**的（随机轴、随机角度），这意味着：
- 训练的是对安装误差**幅度**的容忍度
- 不能补偿系统性的固定偏置（例如 IMU 总是倾斜 5°）
- 系统性偏置需要在运行时校准

## 速度推力

```python
def apply_velocity_push(
    env: ManagerBasedRlEnv,
    env_ids: torch.Tensor,
    velocity_range: tuple[float, float] = (-0.3, 0.3),
):
    """随机推力干扰"""
    robot = env.scene["robot"]
    
    # 采样随机速度变化
    push = uniform(
        velocity_range[0], velocity_range[1],
        size=(len(env_ids), 6),  # [vx, vy, vz, ωx, ωy, ωz]
        device=env.device
    )
    
    # 应用到基座速度
    robot.data.root_lin_vel_w[env_ids] += push[:, :3]
    robot.data.root_ang_vel_w[env_ids] += push[:, 3:]
```

## 非累积性原则（重要！）

### 问题

如果域随机化是累积的，参数会逐渐偏离正常范围：

```
Episode 1: friction = 1.0 * 0.9 = 0.9
Episode 2: friction = 0.9 * 0.9 = 0.81
Episode 3: friction = 0.81 * 0.9 = 0.729
...
Episode 100: friction = 0.000026  ← 完全不合理！
```

### 解决方案

```python
# 正确实现
def randomize_friction(env, env_ids):
    # 1. 先重置到默认值
    actuator.reset_friction_scale(env_ids)
    
    # 2. 采样新值
    scale = uniform(0.9, 1.1, size=(len(env_ids), 1))
    
    # 3. 设置新值
    actuator.set_friction_scale(env_ids, scale)
```

### 历史教训

项目中曾有一个 CoM 随机化函数使用了累积方式，导致：
- 训练初期正常
- 训练后期 CoM 偏移过大
- 策略学会补偿极端偏移
- 部署到真实机器人时失败

这个问题花了数周才定位。

## 课程学习

### 为什么需要课程？

```
训练初期：策略还不知道怎么走路
  → 大范围随机化 = 噪声太大，学不到任何东西
  → 小范围随机化 = 先学会基础技能

训练后期：策略已经会走路
  → 小范围随机化 = 不够鲁棒
  → 大范围随机化 = 提高鲁棒性
```

### 课程配置

```python
curriculum = [
    # 阶段 1：小范围随机化
    {
        "step": 0,
        "com_range": 0.003,
        "friction_range": (0.95, 1.05),
    },
    # 阶段 2：中等范围
    {
        "step": 2000 * 24,  # 2000 次迭代
        "com_range": 0.005,
        "friction_range": (0.9, 1.1),
    },
    # 阶段 3：大范围
    {
        "step": 4000 * 24,
        "com_range": 0.008,
        "friction_range": (0.8, 1.2),
    },
]
```

### 课程节奏

**重要**：课程阶段的转换必须与策略学习进度匹配。

```
错误：过早增加难度
  → 策略还没学会基础技能
  → 性能突然下降
  → 训练失败

正确：等策略巩固后再增加难度
  → 性能稳定后再增加挑战
  → 逐步提高鲁棒性
```

### 验证非累积性

```python
def test_non_accumulating():
    """测试随机化是否非累积"""
    env.reset()
    
    # 记录初始值
    initial_friction = env.actuator.friction_scale.clone()
    
    # 运行多个 episode
    for episode in range(10):
        env.reset()
        
        # 检查是否重置到默认值附近
        current_friction = env.actuator.friction_scale
        deviation = (current_friction - initial_friction).abs().max()
        
        if deviation > 0.2:  # 偏差过大
            print(f"WARNING: 随机化可能是累积的！偏差={deviation:.3f}")
```

## 总结

域随机化是 sim2real 的关键技术：

1. **参数选择**：随机化对 sim2real 差距影响最大的参数
2. **范围设置**：从小范围开始，逐步增加
3. **非累积性**：每次重置必须重新采样，不能累加
4. **课程学习**：根据训练进度调整随机化强度
5. **监控验证**：确保随机化行为符合预期

Microduck 的成功 sim2real _transfer 很大程度上归功于精心设计的域随机化策略。
