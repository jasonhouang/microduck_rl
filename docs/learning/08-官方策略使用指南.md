# 官方策略使用指南

## 概述

Microduck 官方策略包 `pollen-robotics/microduck-policies` 包含 8 个预训练的 ONNX 模型，涵盖行走、摔倒恢复、坐下/站起、捡东西、踢球、翻滚等技能。

## 下载策略包

```bash
cd /home/jason/Workspaces/microduck_rl

uv run python -c "
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id='pollen-robotics/microduck-policies',
    local_dir='official_policies'
)
"
```

## 策略列表

| 策略 | 文件 | 功能 | 触发键 |
|------|------|------|--------|
| 行走 | alpha_walking.onnx | 基础行走，速度控制 | 方向键/A/E |
| 站立 | alpha_stand.onnx | 摔倒后自动恢复 | 自动触发 |
| 坐下/站起 | alpha_sitstand.onnx | 坐姿和站姿切换 | Y |
| 捡东西 | alpha_ground_pick.onnx | 弯腰用嘴捡地面物体 | G |
| 左踢 | ball_kick_left.onnx | 左脚踢球 | K |
| 右踢 | ball_kick_right.onnx | 右脚踢球 | L |
| 轮滑 | roller.onnx | 轮式移动（需轮滑模型） | 方向键/A/E |
| 翻滚 | roulade.onnx | 前滚翻 | R |

## 快速开始

### 1. 基础行走 + 摔倒恢复

最常用的组合，机器人可以行走，摔倒后自动站起来：

```bash
uv run scripts/infer_policy.py \
    --walking official_policies/alpha_walking.onnx \
    --standing official_policies/alpha_stand.onnx \
    --new-cmd-obs
```

**测试摔倒恢复**：按 `P` 给机器人一个随机推力，它会摔倒然后自动站起来。

### 2. 完整技能组合

加载所有技能，体验完整的 Microduck 能力：

```bash
uv run scripts/infer_policy.py \
    --walking official_policies/alpha_walking.onnx \
    --standing official_policies/alpha_stand.onnx \
    --sitstand official_policies/alpha_sitstand.onnx \
    --ground-pick official_policies/alpha_ground_pick.onnx \
    --kick-left official_policies/ball_kick_left.onnx \
    --kick-right official_policies/ball_kick_right.onnx \
    --roulade official_policies/roulade.onnx \
    --new-cmd-obs
```

### 3. 轮滑模式

使用轮滑模型（需要轮滑机器人 XML）：

```bash
uv run scripts/infer_policy.py \
    --walking official_policies/roller.onnx \
    --roller \
    --new-cmd-obs
```

## 控制键详解

### 移动控制（默认模式）

| 按键 | 功能 | 说明 |
|------|------|------|
| ↑ | 前进 | 增加 lin_vel_x |
| ↓ | 后退 | 减少 lin_vel_x（可为负值） |
| ← | 左平移 | 增加 lin_vel_y |
| → | 右平移 | 减少 lin_vel_y |
| A | 左转 | 增加 ang_vel_z |
| E | 右转 | 减少 ang_vel_z |
| SPACE | 停止 | 归零所有速度指令 |

### 技能触发

| 按键 | 功能 | 前提条件 |
|------|------|----------|
| Y | 坐下/站起 | 需要 --sitstand |
| G | 捡东西 | 需要 --ground-pick |
| K | 左脚踢球 | 需要 --kick-left |
| L | 右脚踢球 | 需要 --kick-right |
| R | 前滚翻 | 需要 --roulade |
| P | 随机推力 | 测试摔倒恢复 |
| T | 暂停/恢复 | 暂停策略推理 |
| Q | 退出 | 关闭程序 |

### 视角控制

| 按键 | 功能 |
|------|------|
| 鼠标拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 中键拖动 | 平移视角 |

    --new-cmd-obs

# 操作：
# 1. 按 ↑ 让机器人走起来
# 2. 按 P 给一个推力
# 3. 观察机器人摔倒后自动站起来

    --new-cmd-obs

# 2. 按 G 触发捡东西动作

## 策略切换机制

Microduck 的策略切换是自动的：

1. **行走 → 站立**：当检测到摔倒（倾斜角度过大）时自动切换
2. **站立 → 行走**：当机器人恢复直立后自动切换回行走
3. **技能触发**：按技能键（G/K/L/R/Y）时临时切换到对应策略
4. **技能完成**：技能动作完成后自动切换回行走或站立

## 常见问题

### Q: 按 P 后机器人摔倒了，但没有站起来？

A: 确保加载了 `--standing` 策略：
```bash
--standing official_policies/alpha_stand.onnx
```

### Q: 按 G/K/L/R/Y 没有反应？

A: 检查是否加载了对应的策略文件，例如：
```bash
--ground-pick official_policies/alpha_ground_pick.onnx
```

### Q: 机器人走起来后很快摔倒？

A: 可能是速度指令太大，尝试：
- 轻按方向键，不要长按
- 按 SPACE 归零速度
- 检查是否加载了 `--standing` 策略

### Q: 如何同时使用多个技能？

A: 可以在一个命令中加载多个策略：
```bash
uv run scripts/infer_policy.py \
    --walking official_policies/alpha_walking.onnx \
    --standing official_policies/alpha_stand.onnx \
    --sitstand official_policies/alpha_sitstand.onnx \
    --ground-pick official_policies/alpha_ground_pick.onnx \
    --kick-left official_policies/ball_kick_left.onnx \
    --kick-right official_policies/ball_kick_right.onnx \
    --roulade official_policies/roulade.onnx \
    --new-cmd-obs
```

### Q: 轮滑模式怎么使用？

A: 需要加载轮滑策略和轮滑机器人模型：
```bash
uv run scripts/infer_policy.py \
    --walking official_policies/roller.onnx \
    --roller \
    --new-cmd-obs
```

## 进阶：自定义参数

可以调整一些参数来改变行为：

```bash
uv run scripts/infer_policy.py \
    --walking official_policies/alpha_walking.onnx \
    --standing official_policies/alpha_stand.onnx \
    --lin-vel-x 0.3 \          # 初始前进速度
    --ang-vel-z 0.5 \          # 初始旋转速度
    --kick-duration 3.0 \      # 踢球动作持续时间
    --roulade-duration 2.0 \   # 翻滚动作持续时间
    --new-cmd-obs
```

## 部署到真实机器人

这些策略也可以部署到真实的 Microduck 机器人：

```bash
# 1. 发布策略到 Hugging Face
uv run publish \
    --onnx official_policies/alpha_walking.onnx \
    --repo <your-username>/microduck-walking \
    --kind perpetual \
    --slot walk

# 2. 在机器人上下载
robotctl policy download <your-username>/microduck-walking

# 3. 加载策略
robotctl policy load walk <your-username>/microduck-walking
```

## 总结

官方策略包提供了完整的 Microduck 技能集：

- **基础能力**：行走 + 摔倒恢复
- **交互技能**：捡东西、踢球、翻滚
- **姿态控制**：坐下/站起
- **特殊模式**：轮滑

通过组合不同的策略，可以体验 Microduck 的全部能力。记住关键参数 `--new-cmd-obs`，这是使用 61 维观察空间的必需参数。
