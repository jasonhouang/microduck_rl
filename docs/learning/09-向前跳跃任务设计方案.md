# 向前跳跃任务设计方案

## 概述

训练 Microduck 从站立姿势向前跳跃，完成"下蹲蓄力 → 起跳 → 腾空 → 落地 → 恢复站立"的完整动作序列。

## 物理可行性分析

### 硬件约束

| 参数 | 值 | 说明 |
|------|-----|------|
| 机器人质量 | ~800g | 含电池 |
| 舵机扭矩 | 0.6 Nm (XL330-M288) | 6V 时 |
| 关节速度 | 123 rev/min (6V) | 约 12.9 rad/s |
| 腿部关节数 | 10 (左右各 5) | hip_yaw/roll/pitch, knee, ankle |
| 站立高度 | ~115mm | 躯干到地面 |
| 电池电压 | 7.4V (NP-F550) | 2S Li-ion |

### 跳跃能力估算

```
最大腿伸展力 ≈ 10 个舵机 × 0.6 Nm / 0.05m (力臂) ≈ 120 N
重力 ≈ 0.8 kg × 9.8 ≈ 7.8 N
推力余量 ≈ 120 - 7.8 ≈ 112 N

理论起跳速度 ≈ sqrt(2 × F_net × d / m) 
            ≈ sqrt(2 × 112 × 0.05 / 0.8)
            ≈ 3.7 m/s (垂直分量受关节速度限制)

实际预期：
- 跳跃高度: 5-15 cm (受关节速度和扭矩限制)
- 跳跃距离: 10-30 cm (向前分量)
```

结论：**小幅度跳跃是可行的**，关键是利用腿部关节的快速伸展。

## 任务设计

### 基本结构

```
类型: Episodic (回合制)
触发: 按键触发 (类似踢球 K/L)
时长: 4 秒 (蓄力 + 跳跃 + 落地 + 恢复)
```

### 动作序列

```
时间轴:
  0.0s ──── 0.5s ──── 1.0s ──── 1.5s ──── 2.5s ──── 4.0s
   │         │         │         │         │         │
   │  站立   │  下蹲   │  起跳   │  腾空   │  落地   │  恢复  │
   │         │  蓄力   │  爆发   │         │  缓冲   │  站立  │
   └─────────┴─────────┴─────────┴─────────┴─────────┴────────┘
   
   Phase 1: 下蹲蓄力 (0-0.5s)
     - 髋关节屈曲
     - 膝关节弯曲
     - 踝关节背屈
     - 重心降低
   
   Phase 2: 起跳爆发 (0.5-1.0s)
     - 腿部快速伸展
     - 产生向前+向上的推力
     - 脚离地
   
   Phase 3: 腾空 (1.0-1.5s)
     - 无地面接触
     - 抛物线轨迹
     - 准备落地姿态
   
   Phase 4: 落地缓冲 (1.5-2.5s)
     - 脚触地
     - 屈膝吸收冲击
     - 保持平衡
   
   Phase 5: 恢复站立 (2.5-4.0s)
     - 伸展腿部
     - 回到站立姿势
     - 稳定等待
```

### 奖励设计

#### 主要奖励

```python
# 1. 向前距离奖励 (核心目标)
# 跳跃落地后，测量躯干向前移动的距离
# 使用 potential-based: 奖励增量，不奖励原地停留
forward_distance_reward = (trunk_x - prev_trunk_x) * 5.0
# 只在落地后计算，避免腾空时乱飞

# 2. 落地稳定奖励
# 落地后保持直立，持续给奖励
landing_stable_reward = upright_score * 2.0
# gated on: 双脚触地 + 直立 + 静止

# 3. 跳跃高度奖励 (辅助)
# 鼓励有足够的腾空高度
air_time_reward = air_time * 0.5
# 有腾空时间说明跳跃成功
```

#### 正则化惩罚

```python
# 4. 摔倒惩罚
fall_penalty = -10.0 if fallen

# 5. 动作平滑惩罚
action_rate_penalty = -0.01 * action_rate.norm()

# 6. 能量惩罚
energy_penalty = -0.001 * action.norm()

# 7. 冲击惩罚 (保护舵机)
impact_penalty = -0.05 * abs(acceleration_z)
# 落地时限制冲击，防止舵机过载

# 8. 脚打滑惩罚
foot_slip_penalty = -0.1 * slip_velocity * foot_contact
```

### 观察空间 (61 维，统一格式)

```
Observation (61D):
├── 本体感知 (48D)
│   ├── 角速度 (3D)
│   ├── 投影重力 (3D)
│   ├── 关节位置 (14D)
│   ├── 关节速度 (14D)
│   ├── 历史动作 (14D)
│   └── 相位变量 (0D)
│
└── 控制指令 (13D)
    ├── 速度指令 (3D): [vx, vy, ωz]
    │   └── vx 用于控制跳跃方向 (正=向前)
    ├── 头部姿态 (4D): 零填充
    └── 身体姿态 (6D): 零填充
```

## 风险和注意事项

### 1. 硬件限制

- XL330 舵机可能无法产生足够的爆发力
- 关节速度限制（123 rev/min）影响起跳速度
- 建议：先在小环境中测试，确认物理可行性

### 2. 落地冲击

- 800g 机器人从 10cm 高度落下，冲击力约 80N
- 可能损坏舵机齿轮
- 建议：添加冲击惩罚，训练缓冲落地

### 3. 平衡问题

- 向前跳跃容易前倾摔倒
- 需要精确控制起跳角度
- 建议：课程学习，先学原地跳，再学向前跳

### 4. Sim2real 差距

- 舵机响应延迟
- 地面摩擦差异
- 建议：充分的域随机化，BAM 执行器模型

## 预期训练时间

- 环境数: 4096
- 迭代次数: 5000-8000
- 每次迭代: ~2 秒
- 总时间: 约 28-44 小时

## 成功标准

- 跳跃距离 > 10cm
- 落地后保持直立 > 1 秒
- 摔倒率 < 10%
- 动作平滑，无明显抖动
