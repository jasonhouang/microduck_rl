# 奖励设计

## 概述

奖励函数是强化学习的核心，它定义了策略要优化的目标。Microduck 的奖励设计经过大量实验和迭代，包含许多经验教训。本文档介绍奖励函数的设计原则、常见陷阱和最佳实践。

## 奖励函数结构

### 奖励组成

```python
# 总奖励 = 各项奖励的加权和
total_reward = Σ (weight_i * reward_i)

# 例如：
total_reward = (
    1.0 * tracking_reward      # 跟踪速度指令
    + 2.0 * upright_reward     # 保持直立
    - 0.001 * energy_penalty   # 能量消耗（负权重）
    - 0.01 * smoothness_penalty # 动作平滑（负权重）
    - 0.1 * foot_slip_penalty  # 脚打滑（负权重）
)
```

### 符号约定（重要！）

Microduck 有两种奖励风格：

```python
# 风格 1：mjlab 基础函数
# 返回 >= 0，使用负权重
reward = distance_to_target  # 越大越好
weight = -1.0  # 负权重表示惩罚

# 风格 2：Microduck 自定义函数
# 返回 <= 0，使用正权重
def custom_penalty():
    return -error  # 返回负值
weight = 1.0  # 正权重

# 关键：确保最终加权奖励的符号正确
# 正奖励 = 鼓励的行为
# 负奖励 = 惩罚的行为
```

### 常见错误

```python
# 错误：双重否定变成奖励
def error_penalty():
    return -error  # 返回负值

weight = -1.0  # 负权重
# 结果：-1.0 * (-error) = error > 0
# 策略会最大化错误！

# 正确：保持一致
def error_penalty():
    return -error  # 返回负值

weight = 1.0  # 正权重
# 结果：1.0 * (-error) = -error < 0
# 策略会最小化错误 ✓
```

## 核心奖励项

### 1. 速度跟踪奖励

```python
def track_velocity_vel_xy_reward(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
    command_name: str,
    std: float,
) -> torch.Tensor:
    """跟踪线速度指令"""
    robot = env.scene[asset_cfg.name]
    command = env.command_manager.get_command(command_name)
    
    # 当前速度（基座坐标系）
    vel = robot.data.root_lin_vel_b[:, :2]  # [vx, vy]
    
    # 目标速度
    target_vel = command[:, :2]  # [vx_cmd, vy_cmd]
    
    # 误差
    error = (vel - target_vel).norm(dim=1)
    
    # 高斯奖励（误差越小，奖励越大）
    reward = torch.exp(-error / std)
    
    return reward

# 配置
REWARDS = {
    "track_velocity_vel_xy": RewardTermCfg(
        func=track_velocity_vel_xy_reward,
        params={
            "asset_cfg": SceneEntityCfg("robot"),
            "command_name": "velocity",
            "std": 0.2,  # 标准差：越小越严格
        },
        weight=1.0,
    ),
}
```

### 2. 角速度跟踪奖励

```python
def track_velocity_ang_vel_z_reward(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
    command_name: str,
    std: float,
) -> torch.Tensor:
    """跟踪角速度指令"""
    robot = env.scene[asset_cfg.name]
    command = env.command_manager.get_command(command_name)
    
    # 当前角速度
    ang_vel = robot.data.root_ang_vel_b[:, 2]  # ωz
    
    # 目标角速度
    target_ang_vel = command[:, 2]  # ωz_cmd
    
    # 误差
    error = (ang_vel - target_ang_vel).abs()
    
    # 高斯奖励
    reward = torch.exp(-error / std)
    
    return reward
```

### 3. 直立奖励

```python
def upright_reward(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
) -> torch.Tensor:
    """鼓励保持直立"""
    robot = env.scene[asset_cfg.name]
    
    # 基座朝向（四元数）
    quat = robot.data.root_quat_w
    
    # 投影重力（基座坐标系）
    gravity = quat_apply(quat.inverse(), torch.tensor([0, 0, -1], device=env.device))
    
    # z 分量：-1 表示完全直立，0 表示水平
    upright_score = -gravity[:, 2]
    
    # 归一化到 [0, 1]
    reward = (upright_score + 1) / 2
    
    return reward
```

### 4. 能量消耗惩罚

```python
def action_rate_penalty(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
) -> torch.Tensor:
    """惩罚动作变化率（鼓励平滑）"""
    robot = env.scene[asset_cfg.name]
    
    # 当前动作
    action = env.action_manager.get_action()
    
    # 上一步动作
    prev_action = env.action_manager.get_prev_action()
    
    # 动作变化率
    rate = (action - prev_action).norm(dim=1)
    
    # 返回负值（惩罚）
    return -rate
```

### 5. 脚打滑惩罚

```python
def foot_slip_penalty(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
) -> torch.Tensor:
    """惩罚脚部打滑"""
    robot = env.scene[asset_cfg.name]
    
    # 脚部接触状态
    foot_contacts = robot.data.contact_forces[:, robot.find_bodies(".*_foot")[0], 2] > 1.0
    
    # 脚部水平速度
    foot_vel = robot.data.body_lin_vel_w[:, robot.find_bodies(".*_foot")[0], :2]
    foot_speed = foot_vel.norm(dim=2)
    
    # 接触时速度越大，惩罚越大
    slip = foot_speed * foot_contacts.float()
    penalty = slip.sum(dim=1)
    
    return -penalty
```

## 高斯奖励的标准差选择

### 标准差的意义

```python
# 高斯奖励：reward = exp(-error / std)

# std 小（例如 0.05）：
#   - 只有误差非常小时才有奖励
#   - 梯度陡峭，学习快
#   - 但可能过于严格，难以达到

# std 大（例如 0.5）：
#   - 误差较大时也有奖励
#   - 梯度平缓，学习慢
#   - 但更容易获得初始奖励
```

### 选择原则

```python
# 原则 1：std ≈ 你关心的最小误差
# 例如：速度跟踪精度 0.2 m/s
std = 0.2

# 原则 2：考虑行为固有的波动
# 例如：头部必须摆动以保持平衡
# 不能用太小的 std 惩罚正常摆动

# 原则 3：从大开始，逐步减小
# 训练初期：std = 0.5（容易获得奖励）
# 训练后期：std = 0.1（精确跟踪）
```

### 实例：头部跟踪

```python
# 错误：std 太小
# 头部必须摆动以保持平衡，但惩罚了正常摆动
head_tracking_std = 0.05  # 太严格！

# 正确：使用 EMA 只惩罚 DC 偏移
# 瞬时摆动被平均掉，只惩罚持续偏差
head_ema = exponential_moving_average(head_error, alpha=0.1)
reward = exp(-head_ema / 0.1)
```

## 奖励黑客防范

### 什么是奖励黑客？

```
策略找到了最大化奖励的"捷径"，但没有真正学会任务

例如：
- 任务：向前走
- 黑客：向后翻跟头（因为翻转时高度变化被误认为前进）
```

### 常见黑客行为

#### 1. 臀部跳跃

```python
# 问题：策略通过跳跃获得高度奖励
# 原因：高度奖励没有约束运动质量

# 解决：添加动作平滑惩罚
smoothness_penalty = -action_rate.norm(dim=1)

# 添加能量惩罚
energy_penalty = -action.norm(dim=1)
```

#### 2. 肩滚翻

```python
# 问题：策略通过侧滚翻获得前进奖励
# 原因：只跟踪了线速度，没有约束姿态

# 解决：添加直立奖励
upright_reward = base_orientation_z  # z 轴朝上

# 添加角速度惩罚
angular_vel_penalty = -angular_vel.norm(dim=1)
```

#### 3. 头部三脚架

```python
# 问题：策略用头部支撑地面"站立"
# 原因：高度奖励没有排除异常姿态

# 解决：添加状态门控
# 只有在正常姿态时才给高度奖励
def height_reward_with_gate():
    is_upright = base_orientation_z > 0.8
    height = base_pos_z
    
    # 只有直立时才给奖励
    return height * is_upright.float()
```

### 防范原则

```
原则 1：用硬约束而非软惩罚
  - 软惩罚：-0.01 * tilt_angle（容易被绕过）
  - 硬约束：如果倾斜 > 45°，终止 episode

原则 2：组合多个奖励项
  - 单一奖励容易被黑客
  - 多个奖励项相互约束

原则 3：监控训练过程
  - 观察视频，不要只看奖励曲线
  - 检查异常行为
```

## 终止条件

### 摔倒终止

```python
def fallen_termination(
    env: ManagerBasedRlEnv,
    asset_cfg: SceneEntityCfg,
    max_tilt: float = 0.8,
) -> torch.Tensor:
    """摔倒时终止"""
    robot = env.scene[asset_cfg.name]
    
    # 投影重力
    gravity = quat_apply(
        robot.data.root_quat_w.inverse(),
        torch.tensor([0, 0, -1], device=env.device)
    )
    
    # z 分量：-1 表示直立，0 表示水平
    tilt = gravity[:, 2].abs()
    
    # 倾斜超过阈值
    return tilt > max_tilt
```

### 超时终止

```python
def timeout_termination(
    env: ManagerBasedRlEnv,
    max_time_s: float = 20.0,
) -> torch.Tensor:
    """超时终止"""
    return env.episode_length_buf >= int(max_time_s / env.dt)
```

    for name, value in rewards.items():
        print(f"{name}: mean={value.mean():.3f}, std={value.std():.3f}")

## 最佳实践总结

1. **符号一致**：确保奖励和权重的符号约定一致
2. **从零开始**：先只用主要任务奖励，验证能学会
3. **逐步添加**：一次添加一个正则化项，观察效果
4. **监控视频**：不要只看曲线，要看实际行为
5. **防范黑客**：用硬约束和状态门控防止捷径
6. **标准差选择**：从大开始，逐步减小
7. **权重比例**：比较奖励质量，而非权重数值
8. **课程节奏**：与策略学习进度匹配
